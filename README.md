# 가계부 캘린더

가계부와 캘린더를 합친 개인용 웹앱입니다. 설치 없이 `index.html`을 브라우저로 열면 바로 쓸 수 있습니다.

- **로그인 없이**: 데이터는 그 브라우저(localStorage)에만 저장되며, CSV·JSON으로 백업할 수 있습니다.
- **로그인하면**: 계정별로 서버(Supabase)에 저장되어 휴대폰·PC 어디서나 같은 데이터를 씁니다. 사용자끼리는 서로의 데이터를 볼 수 없습니다.

## 기능

| 화면 | 내용 |
|---|---|
| **대시보드** | 누적 지출·수입·저축률(전년 같은 기간 대비), 월별 지출 3년 비교 그래프, 연도별 수입·지출, 카테고리별 3년 비교, 최근 고정비 이상 알림 |
| **가계부** | 월별 내역, 카테고리별 합계, 카테고리·메모 필터, 거래 추가·수정·삭제 |
| **캘린더** | 날짜별 지출·수입 금액과 여행·일정 표시. 날짜를 누르면 그날 내역을 보고 바로 거래·일정 추가 |
| **고정비 분석** | 가스비·수도비·전기비·주유비 등의 **카테고리 × 월 히트맵**, 3년치 월별 그래프(예년 범위 띠), 월별 판정표 |
| **여행·일정** | 일정마다 연결된 지출을 모아 **기간(박/일)·총지출·1일 평균·항목별 지출** 계산, 연도별 여행 지출 |
| **검색** | `여행` → 모든 여행을 연도·목적지·기간·지출 표로. `2025 여행`, `오사카`, `가스비`, `결혼식`처럼 연도·단어 조합도 가능 |
| **데이터** | CSV 가져오기/내보내기, JSON 백업/복원, 샘플 데이터, 카테고리 관리(고정비 지정), 이상 감지 기준 설정 |

### 고정비 이상 감지 방식

각 고정비 카테고리의 이번 달 금액을 다음 기준과 비교합니다.

1. **예년 같은 달 평균**: 최근 2년(설정에서 1~3년)의 같은 달 금액 평균
2. **올해 추세 보정**: 올해 1월~지난달 합계가 예년 같은 기간보다 n% 높으면 예상치도 n% 올림 (요금 인상 등 반영, 3개월 이상 데이터가 있을 때만 적용)
3. **계절 지수**: 예년에 이 달이 그 해 월평균의 몇 배였는지 확인
   - 겨울 난방비처럼 원래 오르는 달이면 "계절적 상승 시기"로 안내
   - 예년엔 적었던 달에 급등하면 "상승 시점이 평소보다 이르다"고 안내
4. **일정 영향 분리**: 여행 중 주유처럼 일정에 연결된 지출 때문에 늘어난 경우는 `일정 영향`으로 따로 표시

판정: 예상 대비 **+15% 초과 = 주의**, **+30% 초과 = 경고** (설정에서 변경 가능)

## 사용법

```bash
# 그냥 파일을 열어도 됩니다
open index.html            # macOS
start index.html           # Windows

# 또는 로컬 서버로
python3 -m http.server 8000   # → http://localhost:8000
```

처음 열면 **샘플 데이터로 체험하기**를 눌러 최근 3년치 예시 데이터(여행 6건, 의도적으로 넣은 고정비 이상 2건)를 볼 수 있습니다.
실제로 사용하려면 **데이터 → 모든 데이터 삭제** 후 입력하거나 CSV를 가져오세요.

main 브랜치에 푸시하면 `.github/workflows/pages.yml`이 테스트를 돌린 뒤 GitHub Pages로 배포합니다(저장소 Settings → Pages → Source를 **GitHub Actions**로 설정 필요). 휴대폰에서도 열 수 있지만 데이터는 기기·브라우저마다 따로 저장됩니다.

### 거래 내역 가져오기 (카드사 · 은행 · CSV)

**데이터 → 거래 내역 가져오기 → 파일 선택**에서 파일을 고르면 미리보기가 열립니다. 여러 파일을 한 번에 골라도 됩니다.

1. 카드사·은행 홈페이지나 앱에서 **이용내역 / 거래내역을 CSV로** 내려받습니다.
   엑셀(.xls/.xlsx)만 제공되면 엑셀에서 *다른 이름으로 저장 → CSV(쉼표로 분리)* 로 바꿔 주세요.
2. 미리보기에서 형식(카드 이용내역 / 은행 거래내역 / 가계부 CSV), 기간, 건수, 지출·수입 합계를 확인합니다.
3. **가맹점별 카테고리**를 확인하고 필요하면 고친 뒤 가져옵니다.

자동으로 처리하는 것:

| 항목 | 동작 |
|---|---|
| 인코딩 | EUC-KR(CP949)·UTF-8 자동 판별 |
| 헤더 위치 | 상단의 조회기간·안내 문구를 건너뛰고 `이용일자`·`이용금액` 같은 열 이름이 있는 행을 찾음 |
| 열 이름 | 날짜: `이용일자/승인일자/거래일시/매출일자…`, 금액: `이용금액/승인금액/거래금액…` (해외·현지 금액, 잔액, 포인트 열은 제외), 내용: `가맹점명/이용가맹점/적요/내용…` |
| 카드 취소 | `승인구분/취소여부`에 "취소"가 있거나 금액이 음수면 **환불**(그 달 지출에서 차감, `취소` 태그) |
| 은행 | `출금액/입금액` 열 → 지출/수입. 금액 하나에 부호로 표시하는 파일도 지원 |
| 카드대금 | 은행 내역의 카드대금 출금은 기본으로 제외 (카드 내역과 이중 계산 방지, 미리보기에서 끌 수 있음) |
| 중복 | 이미 있는 거래와 날짜·구분·금액·내용이 같으면 건너뜀 → 같은 달 파일을 다시 가져와도 안전 |
| 카테고리 | 가맹점 이름으로 추측(주유소→주유비, 도시가스→가스비, 스타벅스→외식/카페 …). **한 번 고친 가맹점은 다음부터 그 카테고리로** |
| 여행 | 여행 기간에 쓴 지출은 그 여행에 자동 연결 (고정비 제외, 주유비 포함) |
| 합계·소계 행 | 자동으로 건너뜀 |

이 앱의 CSV 형식(내보내기와 같음):

```csv
날짜,구분,금액,카테고리,메모,태그,일정
2025-01-20,지출,182000,가스비,도시가스 요금,,
2025-07-21,지출,96000,교통,간사이 스루패스,해외,오사카 여행
2025-01-25,수입,4350000,급여,월급,,
```

카드사·은행마다 파일 모양이 조금씩 다릅니다. 가져오기가 안 되는 파일이 있으면 **열 이름이 있는 첫 줄**만 알려 주세요 (거래 내용은 필요 없습니다).

### 여행 지출 연결

- 여행을 추가할 때 **기간 중 지출 자동 연결**을 켜면 그 기간의 지출(고정비 제외, 주유비 포함)이 여행에 연결됩니다.
- 항공권·숙소처럼 미리 결제한 지출은 거래 입력 시 **여행·일정 연결**에서 직접 선택하세요.

## 로그인·동기화 설정 (Supabase)

`js/config.js`가 비어 있으면 로그인 버튼이 숨겨지고 브라우저 저장 모드로만 동작합니다. 로그인을 켜려면:

1. [supabase.com](https://supabase.com)에서 무료 프로젝트를 만듭니다.
2. **SQL Editor**에 [`supabase/schema.sql`](supabase/schema.sql) 내용을 붙여넣고 **Run** — `ledgers` 테이블과 “본인 행만 읽기·쓰기” 보안 규칙(RLS)이 만들어집니다.
3. **Authentication → URL Configuration**
   - Site URL: `https://choitree.github.io/notionTemplate/`
   - Redirect URLs: 위 주소 (로컬에서 테스트하려면 `http://localhost:8000/`도 추가)
4. **Project Settings → API**에서 *Project URL*과 *anon(publishable) key*를 복사해 `js/config.js`에 넣고 main에 푸시합니다.
   - anon 키는 브라우저에 공개되는 키라 커밋해도 됩니다. 데이터 보호는 2번의 RLS 규칙이 담당합니다.
   - **service_role 키는 절대 넣지 마세요.**

로그인 방식은 이메일+비밀번호와 이메일 링크(비밀번호 없이 로그인, 비밀번호를 잊었을 때도 사용) 두 가지입니다. Supabase 기본 설정에서는 가입 시 인증 메일을 눌러야 가입이 끝납니다. 기본 메일 발송은 시간당 횟수 제한이 있으니, 사용자가 많아지면 Authentication → SMTP에 자체 메일 서버를 연결하세요.

### 동기화 방식

- 사용자마다 `ledgers` 테이블에 행 하나(가계부 전체 JSON)를 저장하고, 고칠 때마다 1~2초 뒤 자동 저장합니다.
- 두 기기에서 동시에 고치면 거래·일정·카테고리마다 더 최근에 바뀐 쪽을 골라 합칩니다. 삭제도 기록해 두어 지운 항목이 되살아나지 않습니다.
- 창으로 돌아오거나 인터넷이 다시 연결되면 다른 기기의 변경을 가져옵니다. 오프라인에서 입력한 내용은 연결되면 올라갑니다.
- 로그인 전에 이 브라우저에 입력한 데이터가 있으면, 로그인할 때 계정에 합칠지 묻습니다.
- 로그아웃하면 이 브라우저에 남은 계정 데이터 사본을 지웁니다 (서버에는 그대로 남음). 공용 PC에서 쓰기 좋습니다.

## 구조

```
index.html
css/style.css
js/analytics.js   분석 로직 (월·연 합계, 고정비 판정, 일정 요약, 검색) — 순수 함수
js/importer.js    거래 내역 가져오기 (카드사·은행 CSV 형식 판별, 인코딩, 중복, 카테고리 추측)
js/store.js       저장소 (localStorage, 사용자별 캐시, JSON 백업)
js/sync.js        로그인·클라우드 동기화 (Supabase, 기기 간 변경 합치기)
js/config.js      Supabase 주소·공개 키 (비우면 로그인 꺼짐)
supabase/         데이터베이스 스키마·보안 규칙
js/sample.js      샘플 데이터 생성기
js/app.js         화면 (대시보드·가계부·캘린더·고정비·여행·검색·데이터)
js/vendor/        Chart.js 4.4.1 (MIT), supabase-js 2.118.0 (MIT)
tests/            node --test tests/*.test.js
```

빌드 도구 없이 동작하며, 분석 로직은 Node에서도 실행되어 테스트할 수 있습니다.

```bash
node --test tests/*.test.js
```

## Claude Code 설정

`.claude/settings.json`에 [ECC](https://github.com/affaan-m/ECC) 플러그인(`ecc@ecc`)이 등록되어 있어, 이 저장소로 여는 Claude Code 세션에서 ECC의 에이전트·스킬·명령·훅이 자동으로 로드됩니다.
